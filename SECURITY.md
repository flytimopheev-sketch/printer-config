# Политика безопасности

## Поддерживаемые версии

| Версия  | Поддерживается          |
| ------- | ----------------------- |
| 1.2.x   | ✅ Да                   |
| 1.1.x   | ⚠️ Только исправления   |
| < 1.1   | ❌ Нет                  |

## Как сообщить об уязвимости

**Не публикуйте** подробности уязвимости в открытом issue. Используйте
[Security Advisory](https://github.com/flytimopheev-sketch/printer-config/security/advisories/new)
или напишите на `flytimopheev@gmail.com`.

В сообщении укажите:

- версию приложения (помещается в диалог «О программе») и ОС;
- шаги воспроизведения и ожидаемое поведение;
- фактическое поведение и вывод приложения из терминала (при запуске
  `printer-config` в терминале печатаются сообщения `env_logger`).

Ответ ожидается в течение 3 рабочих дней, исправление — в течение 14 дней.

## Что считается уязвимостью

- Выполнение произвольных команд там, где пользователь не ожидает этого
  (например, в именах принтеров, пути к очереди или параметрах `lpadmin`).
- Эскалация привилегий: приложение не должно требовать root там, где
  обходится без него, и не должно выполнять `pkexec` без явной необходимости.
- Несанкционированный доступ к файлам настроек (`%APPDATA%` /
  `~/.config`) или к содержимому очередей.
- Обход границ приложения: чтение файлов за пределами каталога данных,
  инъекция команд в аргументы CUPS.

## Что не считается уязвимостью

- Сообщения об ошибках, раскрывающие путь к файлу или имя пользователя.
- Поведение, требующее локального доступа root (в этом случае нужен другой
  класс защиты, а не исправление приложения).
- Отсутствие шифрования: приложение не хранит секретов и не передаёт их по
  сети.
