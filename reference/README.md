# Справочные материалы

## `system-config-printer.py`

Оригинальная реализация менеджера принтеров из GNOME
([system-config-printer](https://gitlab.gnome.org/GNOME/system-config-printer)),
написанная на Python и распространяемая по **GPL-2.0-or-later**.

Проект Printer Config — перенос этого инструмента на Rust/Tauri с сохранением
основных сценариев:

| system-config-printer (GNOME) | Printer Config (Rust/Tauri)                        |
| ----------------------------- | -------------------------------------------------- |
| Очереди CUPS                 | Вкладка «Принтеры» (CUPS-бэкенд)                   |
| Свойства принтера             | Диалог «Свойства» (место, описание, PPD-опции)     |
| Очередь заданий              | Вкладка «Задания» (отмена, пауза, перезапуск)       |
| Обнаружение сетевых принтеров | Вкладка «Обнаружение» (mDNS/DNS-SD)                 |
| Добавление очереди            | Кнопка «+ Добавить сетевой принтер» (IP/URI/UNC)    |

Файл оставлен **только для справки**: он не входит в сборку приложения, не
входит в RPM-пакет и не распространяется вместе с ним. Лицензия проекта —
